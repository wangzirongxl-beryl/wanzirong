# Assets

## Logo
- `logo/wordmark.svg` — "Zero One 零一 · her" wordmark (typographic placeholder — see note below)
- `logo/monogram.svg` — terracotta circle with italic Z (favicons, avatars, seals)

## Ornaments (small decorative marks / "signs")
- `ornaments/leaf.svg`, `sun.svg`, `asterism.svg`, `wave.svg`, `letter.svg`
- Single-color — they inherit `currentColor`. Use inline and set `color` in CSS.

## Illustrations
Editorial hand-drawn illustrations in the house style (line art, terracotta on cream, occasional rose wash):
- `illustrations/woman-reading.svg` — profile reading, with leaf ornament
- `illustrations/portrait-gesture.svg` — 3/4 head-and-shoulders
- `illustrations/still-life.svg` — cup, books, small plant
- `illustrations/hands-letter.svg` — hands holding a wax-sealed letter

## Textures
- `textures/paper-grain.png` — 240×240 tileable cream paper grain. Applied to `<body>` by default.

## ⚠ Substitution flags (please replace)
- The **logo** is a typographic placeholder in Fraunces italic. If you have a hand-lettered wordmark, swap it in.
- The **illustrations** are in the correct house style but are not by a specific illustrator. If you commission or already own editorial illustrations, drop them in and they'll inherit the system.
